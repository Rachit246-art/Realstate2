# VÉLORA Real Estate — Editorial Luxury Living

> **"A Higher Standard of Living"**  
> An editorial luxury real estate web experience built with pure HTML5, CSS3, and Vanilla JavaScript.

---

## 🏛️ About VÉLORA

VÉLORA is an international luxury property and architectural brand identity. The website design follows an editorial magazine aesthetic with asymmetric compositions, warm ivory and espresso palettes, serif typography, and natural architectural imagery.

### Visual Identity
- **Primary Background**: Warm Ivory (`#F8F6F0`)
- **Secondary Background**: Soft Beige (`#EDE7DC`)
- **Primary Text**: Deep Charcoal (`#191D1A`)
- **Secondary Text**: Muted Taupe (`#827C72`)
- **Accent**: Champagne Beige (`#B99A75`)
- **Dark Sections**: Espresso Brown (`#40372F`)
- **Typography**: *Cormorant Garamond* (headings), *Plus Jakarta Sans* / *DM Sans* (body), and *Playfair Display* (display)

## 🌟 Key Features

1. **Editorial Hero Section**:
   - 3-slide auto-sliding carousel (5.5s interval) with smooth Ken Burns zoom effect.
   - Dual-layer text drop shadows for crystal-clear legibility without heavy dark frames.
   - Dynamic slide content, progress indicators, and full touch swipe support.
2. **Floating Statistics Overlap**:
   - Interactive count-up animations for key metrics (500+ Properties, 50+ Prime Locations, 10K+ Happy Homeowners, 25+ Years of Trust).
   - Circular overlapping badge with animated arrow interaction.
3. **Editorial About Collage**:
   - Asymmetric multi-image architectural layout with overlapping frames and serif typography.
4. **Featured Properties Carousel**:
   - Horizontal slider with touch swipe gestures, dynamic gap calculation, and card hover interactions.
5. **The VÉLORA Experience**:
   - Full-width split layout with organic asymmetric curved SVG border, interactive award badge, and four pillar highlights.
6. **Architectural Materiality & Noble Craft**:
   - Interactive material provenance swatches (Calacatta Gold Marble, Thermo-Treated Nordic Oak, Bronzed Architectural Brass, Hand-Fluted Acoustic Stone) with live preview switching.
7. **Curated Micro-Markets & Destinations**:
   - Distinctive showcase for India's top luxury real estate markets (Gurgaon Golf Course Road, South Delhi Diplomatic Enclave, Mumbai Marine Lines & Worli, Bangalore Whitefield & Indiranagar).
8. **Private Wealth & VIP Concierge Salon**:
   - Dark espresso backdrop with confidential acquisition briefing features.
9. **The Residents Journal**:
   - Editorial architectural essays and thought leadership stories.
10. **Prestige Citations Ribbon**:
    - Global architectural accolades and design honors.

## 📂 Multi-Page Architecture

- `index.html` — Homepage featuring all signature sections and interactive modals.
- `properties.html` — Full portfolio with real-time typology and city filtering.
- `property-detail.html` — Architectural dossier featuring interactive 3/4/5 BHK CAD floor plans, spatial geometry metrics, and high-res gallery.
- `about.html` — Heritage magazine layout, signed founder's letter, and interactive 25-year timeline (2001–2026).
- `services.html` — Alternating editorial rows for Off-Market Acquisitions, Turnkey Architecture, and Private Estate Concierge.
- `communities.html` — Panoramic masterplan banner, four community pillars, and biophilic hydrology metrics.
- `contact.html` — Interactive multi-city office salon switcher (Gurgaon, South Delhi, Bangalore, Mumbai) with confidential consultation booking.

---

## 📱 Responsive & Touch Design

- Fully responsive across all device tiers: 320px compact smartphones, foldables, tablets, and 4K desktops.
- Native touch swipe support on Hero slider, Properties carousel, and Communities carousel.
- Off-canvas luxury mobile navigation drawer with smooth backdrop dismissal.
- Full modal sheet accessibility with auto-contained momentum scrolling.

---

## 💻 Tech Stack

- **HTML5** (Semantic structure, SVG iconography)
- **CSS3** (Custom properties, CSS Grid, Flexbox, smooth transitions, Ken Burns keyframes)
- **Vanilla JavaScript (ES6+)** (No dependencies, IntersectionObserver, Touch Events, count-up animations)

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally:

```bash
# Using Python
python -m http.server 8000

# Using Node
npx serve .
```
